Real-time MIDI call-and-response

A musical partner that listens.

Music Dialogue hears a MIDI phrase, detects when it ends, and answers with new music. It is built for human–AI musical interaction in rehearsal, performance, and research.

Watch the demoRead the paper
Not a loop pedal.The system does not simply repeat what was played. It uses the phrase as a structured MIDI prompt and generates a new response through an autoregressive music model and a real-time control layer.

What the model does

The underlying model generates symbolic-music continuations from MIDI events. It does not receive a natural-language instruction such as “respond to me.”

  • continuous-time note representation
  • temperature-scaled nucleus sampling
  • new MIDI events as the response

What the surrounding system adds

The real-time controller turns continuation into an interactive call-and-response experience.

  • adaptive phrase-end detection
  • duration, repetition, register, and style constraints
  • asynchronous scheduling and playback buffering
